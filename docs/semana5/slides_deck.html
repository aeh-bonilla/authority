BANCO DE RESPUESTAS: Q&A DEL JURADO

P1: ¿POR QUÉ NO POSTGRESQL / BASE DE DATOS TRADICIONAL?

Respuesta: En una base de datos tradicional, la validez depende de confiar en el administrador del servidor. En Stellar, el registro es descentralizado, inmutable e independiente de la empresa, con comisiones de <$0.001 USD.

P2: ¿Y SI ALGUIEN REGISTRA UNA OBRA QUE NO ES SUYA?

Respuesta: La red garantiza la precedencia temporal matemática en un momento del tiempo, no la verdad física. Mateo obtiene una prueba irrefutable de posesión anterior que desmiente cualquier intento de registro posterior.

P3: ¿CUÁNTO CUESTA Y QUIÉN PAGA EL GAS?

Respuesta: Fracciones de centavo. En onboarding, Authory subsidia las transacciones con cuentas operativas para usuarios Web2; en fase avanzada cada usuario o agencia firma con su propia wallet.

P4: ¿CÓMO SE PROTEGE EL ARCHIVO ORIGINAL?

Respuesta: El archivo nunca sube a la red. La Web Crypto API calcula el hash SHA-256 en RAM. Es matemáticamente imposible reconstruir el archivo desde el hash; la privacidad es 100% off-chain.
